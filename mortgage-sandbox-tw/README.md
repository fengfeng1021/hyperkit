# 房貸沙盤 / Mortgage Sandbox TW

> 提前還款、丟 ETF、還是用寬限期？三條淨資產曲線放在同一張時間軸上對撞。

一個純前端的房貸決策模擬器，介面為繁體中文。輸入貸款餘額、年利率、剩餘年限，
把三條路徑放在同一條淨資產時間軸上比較，並且讓每一個假設都能被點開追問。

線上位置：`https://fengfeng1021.github.io/hyperkit/mortgage-sandbox-tw/`

---

## 這個工具在解哪一題

市面上的房貸試算器解的是「我每個月要繳多少」。這個工具解的是**「這筆年終獎金該還房貸還是投資」**。

三條路徑，起始資源完全相同，差別只在錢流去哪裡：

| 路徑 | 期初可動用現金 L | 每月現金流 C 的分配 |
|---|---|---|
| A 全額提前還款 | 依滑桿比例提前還款，其餘投資 | 先付當期月付，剩下的繼續提前還款；貸款清償後才轉入投資 |
| B 只繳月付，差額投資 | 全數投入投資 | 付當期月付，差額全數投資 |
| C 寬限期 + 投資 | 全數投入投資 | 寬限期內只付利息，差額投資；期滿後付重算的月付，差額投資 |

比較基準寫在畫面上（`#ledger` 區塊），不是只寫在文件裡。你不接受這個基準，整張圖對你就沒有意義，你有權知道它是什麼。

## 怎麼用

1. 按「載入範例情境」（或鍵盤 `E`）。三條曲線立刻畫出來。再按一次會換下一個範例，一共三個。
2. 抓住圖表下方的時間軸把手往右拖，三組讀數同步跑。鍵盤也可以：`←` `→` 一個月，`Shift` 加方向鍵一年，`Home` `End` 兩端。
3. 在「你的數字」區塊改成你自己的貸款餘額、年利率、剩餘年限。邊打邊算，不需要按計算。
4. 拉「投資年化報酬」滑桿，看結論在你手上翻轉。
5. 任何一個數字旁邊的小方框都可以點開，看到公式、代入值與出處。
6. 「複製分享連結」把整組參數寫進網址。別人打開會看到一模一樣的圖，包含蒙地卡羅的那一張。

### 輸入的容錯

金額欄位吃得下你會打的所有寫法：

```
1050萬  1,050萬  １０５０萬  1050 萬  NT$10,500,000  10500000
```

全形數字、全形逗號、`萬` `億` `千` 乘數、貨幣符號、空白都會被正確解析。
超出範圍的值一律夾到界限並說明原因，**不會拒絕你的輸入**，因為打錯字的時候最不想看到的是空白的圖。

## 數學

這是這個產品的全部信任基礎，所以每一條都寫在這裡，也寫在介面的抽屜裡。

| 項目 | 做法 |
|---|---|
| 本息均攤月付 | `PMT = P × i / (1 - (1+i)^-n)`，`i = 年利率 / 12` |
| 利率為 0 | 退化為 `PMT = P / n`，不走一般公式 |
| 逐月攤還 | 先算利息 `餘額 × i`，再算本金 `PMT - 利息`，最後扣餘額 |
| 最後一期 | 餘額不足時 `PMT = 餘額 × (1 + i)`，餘額歸零，不留殘值 |
| 提前還款（縮短年限） | 月付不變，`n' = ceil( -ln(1 - 餘額×i/PMT) / ln(1+i) )` |
| 提前還款（縮短月付） | 期數不變，用新餘額與剩餘期數重算 `PMT'` |
| 寬限期 | 期間月付 = `餘額 × i`，本金不動；期滿以剩餘本金與剩餘期數重算 `PMT'` |
| 投資月報酬 | 幾何：`r_m = (1 + 年化)^(1/12) - 1`。**不是** `年化 / 12` |
| 蒙地卡羅 | `sigma_m = 年化波動 / sqrt(12)`，`mu_m = ln(1+年化)/12 - sigma_m²/2` |
| 常態亂數 | Box-Muller，`u1` 排除 0 |
| 亂數源 | 自製 mulberry32，seed 進 URL。整個專案 `Math.random()` 出現 **0** 次 |

### 淨資產的定義

```
淨資產(t) = 房屋價值(t) - 貸款餘額(t) + 投資部位(t) + 現金餘額(t)
房屋價值(t) = 房屋現值 × (1 + 房價年漲幅)^(t/12)
```

「房屋淨值」是「房屋價值減貸款餘額」的另一種說法，它**不是額外的加項**。
常見的寫法「房屋淨值 + 投資 - 剩餘貸款」會把貸款餘額扣兩次，本工具不採用。

### 關於「交叉點」的一個誠實結論

提前還款在數學上等於一張利率為你的**稅後房貸利率**的無風險債券。
因此只要投資報酬高過那個利率，投資在**每一個年份**都領先，根本不存在交叉點。

驗證：把「採列舉扣除」關掉，翻轉門檻會等於你的房貸利率本身，一位小數都不差。
打開列舉扣除、邊際稅率 12%，門檻會降到約 `利率 × 0.88`。這就是它應該有的行為。

所以這個工具不假裝有交叉點。它標的是兩件事：

1. **翻轉門檻**：用二分法求出讓期末淨資產相等的年化報酬，收斂到 0.01%。
2. **決定性月份**：差距首次大過你正在決定的那筆錢（期初現金或一年的可支配現金，取大者）並且之後不再縮回的月份。在那之前，這個決定的金額比你手上的零頭還小。

第二個才是「什麼時候開始有差」的正確答案。

### 台灣在地變數

- **寬限期**：本國房貸特有的產品結構，國外試算器完全沒有。
- **提前清償違約金**：綁約期內按清償本金計收，違約金從你拿出來的那筆錢裡扣，所以真正進本金的比你拿出來的少。
- **轉貸成本**：代書費、抵押權設定登記規費、跑件謄本、徵信帳管費。三條路徑都要付，所以它不改變誰贏，只把三條線一起往下移。
- **房貸利息扣除額**：所得稅法第 17 條，每戶每年上限 30 萬，且須先減除當年度已申報的儲蓄投資特別扣除額。做成開關，因為多數人採標準扣除，這筆一毛都用不到。
- **利率預設**：一般房貸與新青安兩組一鍵套用，標示為參考值，請以你的貸款合約為準。

**假設與資料的界線**：任何我們無法標示出處的數字，一律呈現為「可調假設」，不呈現為「資料」。
抽屜裡不會出現我們編造的小數點。編造的精確度比誠實的粗略更傷信任。

## 技術要點

純靜態、零 build、無後端。直接用瀏覽器開啟 `index.html` 就能完整運作。

```
mortgage-sandbox-tw/
  index.html             方向契約註解 + 完整語意結構 + 內聯 icon sprite
  css/
    tokens.css           唯一的顏色來源。style.css 裡沒有任何裸 hex
    style.css
  js/
    assumptions.js       所有常數、界限、抽屜內容。法規變動只改這一個檔
    samples.js           三組範例情境
    format.js            中文數字解析與格式化
    rng.js               mulberry32 + Box-Muller
    finance.js           攤還、提前還款、寬限期、三路徑、翻轉門檻
    montecarlo.js        分批模擬 + 分位數
    serialize.js         URL hash 與 localStorage
    chart.js             SVG 座標軸與曲線，canvas 扇形
    verdict.js           結論句生成
    drawers.js           「這個數字怎麼來的」
    sheet.js             攤還表與 CSV
    scenarios.js         情境卡與比較欄
    toast.js             訊息條
    motion.js            動效層的接縫（GSAP 缺席時是 no-op）
    main.js              接線
  assets/icons.svg       Tabler Icons (MIT) sprite 原始檔
```

- **無 build**：原生 HTML、原生 CSS 自訂屬性、原生 ES modules。沒有 npm，沒有 bundler，沒有框架。
- **全部相對路徑**：站點服務於 GitHub Pages 的子路徑，任何 `/xxx` 都會 404。
- **GSAP 走 CDN，而且是可選的**：`js/motion.js` 是動效層唯一的接縫。CDN 掛掉、GSAP 不在、或使用者開了 `prefers-reduced-motion`，所有計算、圖表、拖曳、抽屜、匯出都照常運作。CSS 裡沒有任何等 JS 來救的 `opacity: 0`。
- **1000 條蒙地卡羅**：迴圈分批進 `requestAnimationFrame`，量到這台裝置會卡就自動降到 300 條並明說。貸款側是確定的，隨機的只有投資帳戶，所以一次抽樣只需要每月三次乘法。
- **分享連結是人看得懂的**：`#s1~餘額~利率~年限月~...`，刻意不壓縮。一個以透明度為賣點的工具，連它的分享連結都應該看得懂。缺欄位補預設（向後相容），多欄位忽略（向前相容）。
- **CSV 匯出帶 UTF-8 BOM**，否則 Windows 的 Excel 會把中文表頭吃掉。
- **無障礙**：圖表有 `role="img"` 與即時更新的 `<desc>`，旁邊附一張視覺隱藏但螢幕閱讀器讀得到的資料表。三條路徑不靠顏色分辨（同色相三個明度階 **加上** 三種線型），色盲與黑白列印皆可分辨。所有互動元素命中區 >= 44x44。

### 瀏覽器

需要支援 ES modules、CSS 自訂屬性與 `color-mix()` 的現代瀏覽器（Chrome 111+、Firefox 113+、Safari 16.4+）。
沒有 `<canvas>` 時，蒙地卡羅模式會被停用並說明原因，固定報酬模式（純 SVG）完全可用。

## 隱私

**你的數字不會離開這台裝置。**

- 沒有後端，沒有 API，沒有分析追蹤，沒有 cookie。
- 所有計算在你的瀏覽器裡完成。你可以打開 DevTools 的 Network 面板自己確認：除了字型與 GSAP 的 CDN，這個頁面不發任何請求。
- 情境比較欄存在 `localStorage`，鍵名前綴 `mortgage-sandbox-tw:v1:`。它只在你的瀏覽器裡。無痕視窗或空間滿了的時候會降級成「只留在這個分頁」並告訴你。
- 分享連結的參數在 URL 的 `#` 之後。依照 HTTP 規範，`#` 之後的內容**不會被送到伺服器**。但它會出現在你貼上連結的地方，所以貼出去之前想一下那些數字。

## 免責

這是一個試算工具，不是投資建議，也不是稅務建議。

它算的是「在你給的假設之下會怎樣」，不是「未來會怎樣」。
報酬率、波動、房價漲幅都是你自己填的假設；利率、違約金、扣除額規定請以你的貸款合約與當年度法規為準。
真的要動一筆七位數的錢之前，請找你的銀行對帳，並找合格的財務或稅務顧問談過。
