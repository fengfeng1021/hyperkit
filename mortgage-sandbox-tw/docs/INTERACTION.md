## 1. 核心迴圈

### 進站看到什麼

一張**已經畫好座標軸但還沒有標註的圖紙**。x 軸有完整的 0 到 30 年刻度，y 軸留白，圖面中央有一條製圖尺寸線（帶兩端箭頭的水平引線），線上標著「這張圖還沒有數字」，下方一行「載入範例情境，或在下方填入你自己的三個數字」。

這不是「暫無資料」。這是一張**準備好的圖紙**，它已經告訴你這裡將要畫出什麼，只差你的數字。

### 第一個動作

按「載入範例情境」（或按鍵盤 `E`）。這是首屏唯一的實心按鈕。

也可以直接跳到參數台輸入自己的貸款餘額、利率、剩餘年限。輸入到第三個欄位失焦的瞬間，圖自動畫出來，不需要按「計算」。

### 得到什麼

0 到 0.9 秒：三條曲線由左往右畫出來（`stroke-dashoffset` 反向 tween），標題欄的數字滾進去。
0.9 秒後：畫面靜止，三條線清楚分開，legend 顯示三種線型，scrubber 停在第 0 月。

接著使用者抓住 scrubber 往右拖。曲線端點跟著游標跑，三組讀數同步滾動。拖到投資曲線越過提前還款曲線那一格，**招牌動效時刻**觸發（見 §5）。

### 為什麼回來或分享

**回來**：情境比較欄可以存三個情境，存在 localStorage。年終獎金的金額每年不同，利率會變，寬限期會到期。這是一個每年至少開一次的工具。

**分享**：URL hash 完整還原情境，包含蒙地卡羅的 seed。貼進 PTT home-sale 或 Dcard 房屋板，對方打開看到的是**一模一樣的那張圖**，討論才成立。複製連結後 toast 會提示「這個連結包含你所有的參數，別人打開會看到同一張圖」。

## 2. 完整狀態機（逐一物件）

通用約定：

- `:focus-visible` 統一為 `box-shadow: 0 0 0 2px var(--paper), 0 0 0 4px var(--ink-700)`（雙環，內環同底色作為間隙）。滑鼠點擊不顯示，鍵盤操作才顯示。
- `:active` 統一為 `transform: translateY(1px)`，時長 `--t-tap`（90ms）。
- 所有 disabled 元素保留在 Tab 序列外（`tabindex="-1"` 或原生 disabled），但**必須**有 `title` 或相鄰說明文字講清楚為什麼不能按。
- 過場一律 `--e-out`（`cubic-bezier(.16,1,.3,1)`），時長 `--t-ui`（160ms）。

### 2.1 主要按鈕 `.btn--primary`（載入範例情境）

| 狀態 | 視覺 | 進入事件 | 離開事件 |
|---|---|---|---|
| idle | 底 `--ink-700` #12305C，字 `--paper` #F7F9FC（13.10:1），radius 2px，padding 12/20，陰影 `--sh-1` | 預設 | - |
| hover | 底 `--ink-900` #0B2140，陰影升至 `--sh-2`，位移 `translateY(-1px)` | `pointerenter` | `pointerleave` |
| focus | idle 視覺 + focus ring | `focus-visible` | `blur` |
| active | 底 `--ink-900`，`translateY(1px)`，陰影降回 `--sh-1` | `pointerdown` / `keydown Enter,Space` | `pointerup` / `keyup` |
| loading | 標籤換成「計算中」，左側 12px 掃描帶（1px hairline 由左往右掃，1.1s 循環），按鈕 `aria-busy="true"`，`pointer-events: none` | 送出後 > 120ms 仍未完成 | 計算完成 |
| success | 不變更按鈕。成功的證據是圖畫出來了 | - | - |
| error | 按鈕回 idle。錯誤顯示在被拒絕的欄位旁 | - | - |
| disabled | 底 `--paper-sunk`，字 `--ink-300`（3.21:1，僅限非必要資訊），1px `--rule` 外框，無陰影，`cursor: not-allowed` | 已載入範例且參數未改動 | 任一參數改動 |

**loading 是真的**：蒙地卡羅 1000 條路徑在慢機器上要 200 到 600ms，分批進 rAF，期間按鈕確實處於 loading。固定報酬模式下 < 16ms，直接跳過 loading 狀態。

### 2.3 數值輸入 `.numfield`（貸款餘額、年利率、剩餘年限、可動用現金、每月可支配）

結構：label 在上，輸入框，helper 在下（永遠存在於 markup，錯誤時內容被錯誤訊息取代）。無 placeholder-as-label。

| 狀態 | 視覺 |
|---|---|
| idle | 底 `--paper-raised` #FFFFFF，內縮 1px `--rule` 外框，radius 2px，值用 JetBrains Mono `--fs-md` `--ink-900` tabular-nums，右側單位後綴 `--ink-500` 11px mono，左側 label `--fs-xs` `--ink-500`（6.45:1） |
| hover | 外框 `--ink-300` |
| focus | 外框 `--ink-700` 1px + focus ring；同時該欄位對應的假設抽屜觸發器亮起（外框 `--ink-500`），暗示「這裡可以追問」 |
| active | 不另設（輸入框沒有 active 的意義） |
| filled | 同 idle。若值不等於預設值，label 右側出現一個 6x6 的實心方塊 `--signal`，`title="已改為你的數值"` |
| empty | 值區顯示該欄位的預設值，字色 `--ink-400`（5.47:1，通過 4.5），並在 helper 標示「預設值，可直接改」。**不使用灰色 placeholder** |
| error | 外框保持 1px `--rule`，加 `box-shadow: inset 0 -2px 0 var(--signal-ink)`（底線，不是 border-left），helper 換成 `--signal-ink` #B8480F（5.01:1）的錯誤訊息，`aria-invalid="true"` `aria-describedby` 指向 helper |
| clamped | 值被自動夾到界限。欄位閃一次底色（`--signal` 8% alpha，180ms 進、420ms 出），helper 顯示「已調整為上限 40 年」，狀態 3 秒後自動回 idle |
| disabled | 底 `--paper-sunk`，字 `--ink-400`，外框 `--grid-major`。發生於：寬限期欄位在「無寬限期」時；蒙地卡羅參數在固定報酬模式時 |

**輸入行為**：
- 邊打邊算（`input` 事件，160ms debounce），失焦時做一次 clamp 與格式化（千分位）。
- 中文全形數字、逗號、空白、`萬`、`元` 一律容錯解析：`1,050萬` → `10500000`，`1050 萬` → `10500000`，`１０５０萬` → `10500000`。
- 上下方向鍵微調（利率 0.01%、年限 1 年、金額 1 萬）；Shift + 上下為 10 倍步進。
- 每個欄位右側有一個 12x12 的抽屜觸發器（見 2.7）。

### 2.4 滑桿 `.slider`（投資年化、年化波動、房價漲幅、提前還款比例、邊際稅率）

視覺語言是製圖尺規，不是 iOS 滑桿。

- track：2px 高的 `--paper-sunk`，上緣一條 1px `--rule`。track 上方每 5 個單位有一根 4px 的刻度線 `--grid-major`，主刻度 8px 並標數字（mono 11px `--ink-500`）。
- fill：從左端到 thumb，`--ink-700` 2px。
- thumb：12 x 12 實心方塊 `--ink-700`，radius 2px，加 `--sh-1`。thumb 正上方 20px 處是即時數值（mono `--fs-sm` `--ink-900`，tabular-nums，跟著 thumb 移動）。

| 狀態 | 視覺 |
|---|---|
| idle | 如上 |
| hover | thumb 放大到 14x14（transform scale，不動 width），上方數值加粗到 500 |
| focus | thumb + focus ring，數值上方出現「← →」提示（`--fs-2xs` `--ink-400`），3 秒後淡出 |
| active（拖曳中） | thumb 16x16，陰影升 `--sh-2`；**整張圖進入低成本重繪模式**：蒙地卡羅扇形凍結為上一次的點陣圖，只重畫三條主曲線；放開後 120ms 重算扇形 |
| disabled | track `--grid-major`，thumb `--ink-300` 空心 1px，數值 `--ink-400`。發生於：波動滑桿在固定報酬模式 |
| error | 滑桿不會有錯誤（範圍由 min/max 保證） |

原生 `<input type="range">` 加自訂樣式，保留完整鍵盤與無障礙行為。`--track-fill` 用 CSS 自訂屬性由 JS 更新，避免動 width。

### 2.5 時間軸 scrubber `.scrubber`（招牌互動）

`role="slider"`，`aria-valuemin="0"` `aria-valuemax="359"` `aria-valuenow` `aria-valuetext="第 11 年 3 個月"` `aria-label="時間軸游標"`。

- track：圖表下方 32px 高的帶狀區，底 `--paper-sunk`，上下各 1px `--rule`。track 內每年一根 4px 刻度，每 5 年一根 10px 刻度加年份數字。
- handle：14px 寬 x 28px 高的實心 `--ink-700` 方塊，radius 2px，中央有兩根 1px 的 `--paper` 縱向紋（抓握感，drafting 遊標的語言），`--sh-2`。
- 從 handle 往上延伸一條 1px `--ink-500` 虛線（dash 2 3）貫穿整個圖面，這是讀值游標線。游標線與三條曲線的交點各畫一個 4px 空心圓。

| 狀態 | 視覺 | 進入 | 離開 |
|---|---|---|---|
| idle | 如上，游標線 40% 不透明 | 預設 | - |
| hover（在 track 上） | 游標線升到 70%，handle 加寬到 16px，滑鼠所在月份在 track 上浮出一個 11px mono 的年月標籤 | `pointerenter` track | `pointerleave` |
| focus | handle + focus ring，游標線 100%，圖表右上角出現鍵盤提示列「← → 一個月　Shift 一年　Home End 兩端」 | `focus-visible` | `blur` |
| active（拖曳中） | handle 底色 `--ink-900`，`--sh-3`，游標線 100% 且改為實線，三條曲線在游標右側降到 45% 不透明（左側是「已發生」，右側是「還沒到」的製圖表達） | `pointerdown` on handle 或 track | `pointerup` / `Esc` |
| inertia（放手滑行） | 同 active，但 handle 不再跟隨指標，`InertiaPlugin` 慣性滑行後 snap 到最近的月份格 | `dragend` | 慣性結束 |
| disabled | handle `--ink-300` 空心，track `--grid-major`，游標線隱藏。發生於：尚未載入任何情境（空狀態） | 無曲線資料 | 曲線資料到位 |
| crossing（跨越交叉點的那一格） | 觸發招牌動效時刻，見 §5 | `month === crossMonth` 且方向為進入 | 反向跨回 |

**Esc 於拖曳中**：取消該次拖曳，handle 動畫回到起拖位置（0.28s `power3.out`），讀數同步回捲。

**鍵盤**：
| 鍵 | 動作 |
|---|---|
| `←` `→` | 1 個月 |
| `Shift + ←` `Shift + →` | 12 個月 |
| `PageUp` `PageDown` | 12 個月 |
| `Home` | 第 0 月 |
| `End` | 最後一月 |
| `X` | 直接跳到交叉點（若存在） |

鍵盤跨越交叉點時，招牌動效時刻**照樣觸發**。這不是滑鼠專屬的獎勵。

### 2.7 假設抽屜 `.drawer`（這個數字怎麼來的）

用原生 `<details>` / `<summary>`，確保無 JS 也能開合、確保搜尋引擎與 Ctrl+F 找得到內容。

觸發器（`<summary>`）：12x12 的方形框，內含一個繪製的 SVG 問號引線符號（不是 emoji、不是 Unicode `?`）。線寬統一 1.25px，端點方形，與全站圖示系統一致。

| 狀態 | 視覺 |
|---|---|
| idle | 1px `--ink-300` 外框，符號 `--ink-500` |
| hover | 外框 `--ink-700`，符號 `--ink-900`，底 `--paper-sunk` |
| focus | idle + focus ring |
| open | 外框與符號 `--signal`，符號旋轉 45 度（0.2s） |
| disabled | 不存在。每一個假設都必須可追問，沒有例外 |

抽屜內容（展開時）：
- 底 `--paper-raised`，1px `--rule`，radius 4px，`--sh-2`，上緣有一條 2px 的 `--signal` 起始 8px 長的短標記（drafting 的引出線起點），不是彩色 border-left。
- 三段：**公式**（等寬，`--paper-sunk` 底，可選取）／**代入值**（每行一個變數，變數名等寬，值等寬右對齊）／**來源**（`--fs-2xs` `--ink-500`，若無出處則明寫「這是假設，不是資料。預設值 X，請依你的情況調整」）。
- 展開動畫：`height: 0 → auto` 用 GSAP 量測後的固定值 tween（0.3s `power3.out`），內容 `y: -6 → 0`、`autoAlpha: 0 → 1`（0.24s，delay 0.06s）。收合為反向、0.22s。
- 同一時間可以開多個抽屜（對照公式時需要），不是 accordion。

`Esc`：關閉當前 focus 所在或最後開啟的抽屜，焦點回到其 summary。

### 2.8 情境卡 `.chip` 與比較欄 `.tray`

情境卡是這個頁面上**唯一**的卡片，因為情境確實是一個可以被拿起來、拖到別處的離散物件。

卡片內容：情境名稱（可就地編輯）、三個路徑的第 30 年淨資產（mono 右對齊）、交叉年月、一枚 48x24 的縮圖（三條曲線的極簡版，SVG，不是 sparkline 裝飾，是真的資料）。

| 狀態 | 視覺 |

| idle | 底 `--paper-raised`，1px `--rule`，radius 4px，`--sh-1` |
| hover | `--sh-2`，`translateY(-2px)`，右上角浮出刪除觸發器 |
| focus | idle + focus ring |
| dragging | `--sh-3`，`rotate: -1.2deg`，`scale: 1.03`，原位留下 1px 虛線 `--rule` 的空位 |

| in-tray | 卡片吸附進格子，用 GSAP `Flip` 從拖曳位置吸到格線位置（0.34s `power3.out`）；圖表上同步畫出該情境的第 A 條曲線的淡色描邊（`--ink-300` 1px dash 1 3） |
| loading | 縮圖區顯示 3 條 1px 掃描線由上往下移（骨架，不是轉圈） |
| empty（比較欄無情境） | 三個 1px 虛線 `--rule` 的空格，中央文字「調好一組參數後按『存成情境』，拖到這裡並排比較」，第一個空格內有一個繪製的箭頭指向「存成情境」按鈕 |
| error | 見 §4.5（localStorage 滿） |

鍵盤替代拖放（必須有）：卡片 focus 時按 `Enter` 進入「移動模式」，`←` `→` 選擇目標格，`Enter` 放下，`Esc` 取消。移動模式下卡片有 2px `--signal` 外框並在 `aria-live="polite"` 播報「移動模式，左右鍵選擇位置，Enter 放下」。

### 2.9 結論列 `.verdict`

一句可以被念出來的中文句子，隨參數即時改寫。金額與年月是 mono，句子其餘部分是 Noto Sans TC。

範例輸出：
> 在你設定的 **年化 6.0%** 之下，投資會在 **第 11 年 3 個月** 追過提前還款，30 年後多出 **NT$ 1,842,000**。翻轉門檻是 **年化 4.63%**。

強調的四段是 `--signal-ink`（5.01:1）加 500 字重，不是漸層、不是螢光筆。

| 狀態 | 視覺／文案 |
|---|---|
| idle | 如上 |
| recalculating | 數字部分用 `gsap.quickTo` 滾動到新值（0.22s `power2.out`），句子結構若改變則整句 `autoAlpha` 0.35 → 1（0.2s），不是重新打字 |
| no-crossing（30 年內不交叉） | 「在你設定的 **年化 4.0%** 之下，投資在 30 年內都沒有追上提前還款。要追上需要 **年化 4.63%** 以上。」 |
| always-ahead（一開始就領先） | 「在你設定的 **年化 9.0%** 之下，投資從第一個月就領先。這通常代表你的報酬假設偏高，往下拉看看門檻在哪裡。」 |
| shortfall（可支配現金低於月付） | 「你的每月可支配 **NT$ 38,000** 低於本息月付 **NT$ 44,120**。三條路徑都會出現缺口，先把可支配調到 **NT$ 44,120** 以上。」加一個「調到剛好夠」按鈕 |
| empty | 「載入情境後，這裡會出現一句你可以念給另一半聽的結論。」 |

### 2.10 攤還表 `.sheet`

`<table>`，`<caption>` 說明這是哪一條路徑的攤還。預設收合為年度摘要（30 列），可切換逐月（360 列，虛擬捲動）。

- 表頭 sticky，底 `--paper`，下緣 1px `--ink-300`。
- **不在每一列畫 border**。每 5 列一條 1px `--grid-major` 分隔（呼應方格紙的 5 格節奏），其餘用 `--paper` 與 `--paper-sunk` 交替底色分辨。
- 數字全部 mono、tabular-nums、右對齊、小數位對齊。
- hover 該列：底 `--paper-sunk`，且該年在圖表上對應的 x 位置浮出一根 1px `--signal` 的垂直標線。表與圖是連動的，不是兩個獨立東西。
- 匯出 CSV 按鈕（`Blob` + `URL.createObjectURL`，UTF-8 BOM 以免 Excel 中文亂碼）。

### 2.11 Toast `.toast`

右下角，底 `--ink-900`，字 `--paper`（16.08:1），radius 2px，`--sh-3`，最大寬 340px。`role="status"` `aria-live="polite"`；錯誤級用 `role="alert"` `aria-live="assertive"`。

進場：`y: 12 → 0`、`autoAlpha 0 → 1`（0.26s `power4.out`）。停留 4.5 秒（錯誤級 8 秒，或帶動作按鈕時不自動關閉）。出場：`y: 0 → 6`、`autoAlpha → 0`（0.2s）。

同時最多顯示 2 則，第 3 則進來時最舊的立即出場。

### 3.3 Esc 的行為階梯

由上往下第一個成立的執行：

1. scrubber 正在拖曳 → 取消該次拖曳，回到起拖位置
2. 情境卡在鍵盤移動模式 → 取消移動，卡片回原位
3. 快捷鍵說明 dialog 開啟 → 關閉，焦點回觸發者
4. 有抽屜開啟 → 關閉最後開啟的那一個，焦點回其 summary
5. 有 toast 帶動作按鈕 → 關閉該 toast（視為取消）
6. 焦點在文字輸入欄 → 還原該欄位到上一個提交過的值，並失焦
7. 以上皆非 → 焦點移到 scrubber（回到工作台）

### 3.4 焦點可見性

- `:focus-visible` 才顯示 ring，滑鼠點擊不顯示。
- ring 為雙環：內環 2px `--paper`（與底色同色，製造間隙），外環 2px `--ink-700`（12.42:1）。在 `--paper-sunk` 上時內環改用 `--paper-sunk`。
- 在圖表 SVG 內的 focusable 元素，ring 用 `stroke` 屬性實作，不用 `box-shadow`。
- 捲動觸發的 focus 一律 `scrollIntoView({block:'center'})`，避免 focus 元素卡在 sticky nav 底下。

## 4. 失敗路徑

每一條都寫出：偵測方式、使用者看到什麼、如何復原。文案為最終文案，不是佔位。

### 4.1 URL hash 解析失敗

**偵測**：版本前綴不是 `s1`、欄位數 < 8、任一必要欄位 `Number.isFinite()` 為 false。

**畫面**：套用預設值並正常出圖（絕不空白畫面）。toast（`role="alert"`，不自動關閉）：

> 分享連結有一段讀不出來，已經用預設值把缺的補齊了。你可以直接改成你的數字。

附一個「看看原始連結」按鈕，展開顯示原 hash 字串（可選取），方便回報。原 hash 同時 `console.warn` 出來。

**復原**：使用者直接改參數即可，改動後 hash 立即重寫為合法格式。

### 4.2 數值超界

**界限表**（全部集中在 `js/assumptions.js` 的 `BOUNDS`）：

| 欄位 | 下界 | 上界 | 越界處置 |
|---|---|---|---|
| 貸款餘額 | 100,000 | 200,000,000 | clamp |
| 年利率 | 0 | 20 (%) | clamp |
| 剩餘年限 | 1 | 40 (年) | clamp |
| 寬限期 | 0 | `剩餘年限 - 1` | clamp，並說明「寬限期不能等於或超過剩餘年限」 |
| 可動用現金 | 0 | 貸款餘額 | clamp 到貸款餘額，說明「超過餘額的部分沒有地方還」 |
| 每月可支配 | 0 | 2,000,000 | clamp |
| 投資年化 | -10 | 20 (%) | 滑桿本身限制 |
| 年化波動 | 0 | 60 (%) | 滑桿本身限制 |
| 房價年漲幅 | -10 | 15 (%) | 滑桿本身限制 |
| 蒙地卡羅路徑數 | 100 | 2,000 | clamp，說明「超過 2000 條會拖慢拖曳」 |

**畫面**：欄位進入 `clamped` 狀態（底色閃一次 `--signal` 8%），helper 換成：

> 已改成 40 年。這個工具的計算範圍是 1 到 40 年。

**永不拒絕輸入**。一律 clamp 並說明，因為使用者打錯字時最不想看到的是空白的圖。

### 4.3 每月可支配低於本息月付

這**不是錯誤**，是一個真實會發生的情況（例如寬限期即將到期的人）。

**畫面**：結論列切到 `shortfall` 狀態（見 2.9），三條曲線照畫，但缺口的月份在 x 軸上以 1px `--signal-ink` 的短刻度標出，圖表左上角出現一行標註「第 37 到 360 月有現金缺口，圖上以刻度標示」。

**復原**：結論列的「調到剛好夠」按鈕把每月可支配設到 `ceil(PMT / 1000) * 1000`。

### 4.4 GSAP CDN 載入失敗

**偵測**：`</body>` 前的 inline module 檢查 `typeof window.gsap === 'undefined'`。

**畫面**：頁面完全正常運作。所有計算、圖表、拖曳（改用原生 `pointerdown/move/up`）、抽屜（原生 `<details>`）都不依賴 GSAP。

**實作**：`js/motion.js` 匯出一個 `motion` 物件。GSAP 在場時它是薄包裝；不在場時是 no-op shim（`to/from/set` 直接把終態寫進 style，`timeline` 回傳一個立即完成的假物件）。

> 這條是硬要求：內容預設可見，CSS 裡不得出現任何等 JS 來救的 `opacity: 0`。曲線的 `stroke-dashoffset` 起始值由 JS 在確認 GSAP 存在後才寫入，CSS 預設是完全畫好的線。

### 4.5 localStorage 滿了或被停用

**偵測**：`try { localStorage.setItem(probe) } catch (e) { ... }`，捕捉 `QuotaExceededError` 與 Safari 無痕模式的 `SecurityError`。

**畫面**：toast（`role="alert"`，帶動作，不自動關閉）：

> 瀏覽器存不下這個情境（空間滿了或是無痕視窗）。你的網址列已經包含全部參數，先複製起來就不會弄丟。

按鈕兩個：「複製分享連結」、「清掉本站存的情境」。

**降級**：情境比較欄改為 session-only（存在記憶體），並在比較欄上緣加一行 `--fs-2xs` `--ink-500` 的說明「這次的情境只留在這個分頁，關掉就沒了」。

### 4.6 剪貼簿不可用

**偵測**：`navigator.clipboard?.writeText` 不存在，或 `writeText` reject（非 https 或權限被拒）。

**畫面**：toast 內就地顯示一個 `<input readonly>` 已選取全文，文案：

> 這個瀏覽器不讓我直接複製。連結已經選好了，按 Ctrl + C（Mac 是 Cmd + C）。

### 4.7 蒙地卡羅計算過慢

**偵測**：`performance.now()` 量測第一批 100 條路徑的耗時，外推總時間 > 1200ms。

**畫面**：按鈕進入 loading，圖表區出現骨架（三條 1px hairline 由上往下掃過圖面，1.1s 循環，`--ink-300`），下方 mono 文字「模擬 1000 條路徑，已完成 340」。完成後骨架淡出，扇形淡入。

**降級**：外推 > 4000ms 時自動降到 300 條，toast：

> 這台裝置跑 1000 條路徑會卡，已改成 300 條。想跑滿的話在下方把路徑數調回去。

### 4.8 Canvas 或 `OffscreenCanvas` 不支援

**偵測**：`canvas.getContext('2d')` 回傳 null。

**畫面**：蒙地卡羅模式的分段切換進入 disabled 並附 `title="這個瀏覽器不支援畫布，只能用固定報酬模式"`。固定報酬模式（純 SVG）完全可用。

`OffscreenCanvas` 不支援時退回一般 `document.createElement('canvas')`，功能相同，只是繪製不在 worker，會在主執行緒分批進 rAF。

### 4.9 視窗過小或縮放過大

**偵測**：`ResizeObserver` 量到圖表容器寬 < 280px。

**畫面**：圖表 x 軸刻度從「每 5 年」降到「每 10 年」，legend 從橫排改直排，scrubber 的年月標籤只顯示年。不出現橫向捲軸，不出現「請使用桌機」。

### 4.10 使用者輸入了會讓數學爆掉的組合

| 組合 | 處理 |
|---|---|
| 年利率 = 0 | `PMT = P / n`，不走一般公式。抽屜說明這個退化 |
| 剩餘年限 = 0 | 由 clamp 保證下界 1，不會發生 |
| 可動用現金 >= 貸款餘額（路徑 A 一次還清） | 路徑 A 的曲線從第 0 月起就沒有貸款餘額，違約金照算，之後全部轉投資。這是合法情境，正常畫 |
| 提前清償違約金 > 節省的利息 | 正常畫，並在結論列補一句「這筆提前還款的違約金 NT$ X 大於它省下的頭三年利息」 |
| 投資年化為負 | 正常畫。投資曲線往下，這是使用者想看的壓力測試 |

## 5. 招牌動效時刻：交叉點誕生

**動機**（一句話）：讓使用者在生理上感覺到「結論在這裡翻轉」，因為這個產品的全部價值就是那個翻轉點的位置。

**觸發**：scrubber 的當前月份 `m` 由 `m < crossMonth` 變成 `m >= crossMonth`（拖曳、慣性滑行、鍵盤方向鍵、按 `X` 皆可觸發）。反向跨回時整條時間軸 `reverse()`（`timeScale(1.6)`）。

**時間軸 `crossTL`（總長 1.18s）**：

| 起點 | 對象 | 動作 | 時長 / 緩動 |
|---|---|---|---|
| 0.00 | `#cross-dot` 4px 實心圓 `--signal` | `scale: 0 → 1` | 0.34s `back.out(2.2)` |
| 0.00 | `#cross-ring` r=6 空心圓 `--signal` 1.5px | `scale: 0.4 → 3.2`，`autoAlpha: 1 → 0`，`svgOrigin` 設在交叉座標 | 0.62s `power2.out` |
| 0.10 | `#cross-leader` 由交叉點往上 64px 的 1px 直線 | `strokeDashoffset: len → 0`（原生 dash，不引 DrawSVGPlugin） | 0.42s `power3.out` |
| 0.30 | `#cross-wash` 交叉點右側的矩形，fill `rgba(232,106,43,.09)`，上緣 1px `--signal` 35% | `clipPath: inset(0 100% 0 0) → inset(0 0% 0 0)` | 0.72s `expo.out` |
| 0.30 | `#cross-tick` x 軸上的 10px 刻度與年份標籤 | `y: 6 → 0`，`autoAlpha: 0 → 1` | 0.30s `power3.out` |
| 0.34 | `#cross-pill` 標註框（底 `--paper-raised`，1px `--signal`，radius 4px，`--sh-2`） | `scaleX: 0.2 → 1`，`scaleY: 0.6 → 1`，`autoAlpha: 0 → 1`，`transformOrigin: "left bottom"` | 0.36s `power4.out` |
| 0.46 | pill 內文字逐字（本地 splitter，`[...str]` 對 CJK 安全，不引 SplitText） | 每字 `yPercent: 40 → 0`，`autoAlpha: 0 → 1`，`stagger: 0.022` | 每字 0.28s `power3.out` |
| 0.62 | 蒙地卡羅扇形的 P10 / P90 邊界線 | `--fan-breath` 自訂屬性 0 → 1.5，驅動 1.5px 垂直位移，`repeat: -1` `yoyo: true` | 3.2s `sine.inOut` |

pill 文案（動態）：`第 11 年 3 個月，投資開始領先`。無交叉時不建立這條時間軸，pill 改為靜態文字「30 年內投資沒有追上提前還款」。

**參數改變時的反向**：報酬率滑桿往下拉 → `crossTL.reverse()`（標註收回）→ `onReverseComplete` 重算 `crossMonth` → 交叉點沿曲線滑到新的 x（`gsap.to(crossGroup, {x: newX, duration: 0.5, ease: "power3.inOut"})`）→ `crossTL.restart()` 在新位置重新爆開。整段是連續變形，不是重畫。

**效能**：`crossTL` 只動 transform、autoAlpha、`clip-path`、`stroke-dashoffset`，不動 layout 屬性。蒙地卡羅 1000 條路徑在參數改變時繪一次到 offscreen canvas，拖曳期間只 `drawImage` + 更新三條 SVG path 的 `d` 與讀數文字。目標 60fps。

**`prefers-reduced-motion`**：用 `gsap.matchMedia()` 包住。`reduce` 條件下不建立 `crossTL`，改為在交叉月份到達時直接 `gsap.set()` 所有終態（dot、leader、pill、wash、tick 全部立即到位），不建立呼吸循環，讀數直接寫 `textContent` 不做滾動。**資訊完全不損失，只是不動**。

## 6. 首次到訪（零資料）

### 看到什麼

如 §0.2 的線框。要點：

- 圖表**不是空的**。座標軸、方格底紋、0 到 30 年的完整 x 軸刻度全部已經畫好。這是一張準備好的圖紙。
- 圖面正中央一條製圖尺寸線（水平線兩端各一個 45 度的箭頭端點，drafting 的 dimension line 語言），線的上方標著「這張圖還沒有數字」。
- 尺寸線下方一行 `--fs-sm` `--ink-500`：「載入範例情境，或在下方填入你的貸款餘額、利率、剩餘年限。」
- legend 的三條線型已經畫出來，但顏色降到 `--ink-300`，標籤為「提前還款 / 投資差額 / 寬限期 + 投資」。使用者在按下任何東西之前，已經知道這張圖會給他三條什麼線。
- scrubber 處於 disabled 狀態（空心 handle），因為還沒有東西可以刷。

### 為什麼不直接載入範例

因為「載入範例」這個動作本身就是第一次的曲線繪入動畫，那是進入招牌動效時刻的引子。直接預載會把這個時刻白白丟掉，而且使用者會分不清哪些數字是他的、哪些是我們塞的。

### 範例資料的標示

載入後：

1. 標題欄右上角出現一枚 1px `--signal` 外框、radius 2px 的方形標記，內含 mono 11px `--signal-ink` 的「範例情境」。這枚標記在任何一個參數被改動的瞬間消失，換成「你的情境」（`--ink-500` 外框）。

3. 攤還表的 `<caption>` 在範例狀態下寫「範例情境的攤還表」。

## 7. 狀態持久化與序列化

### 7.1 URL hash 格式（v1）

```
#s1~<餘額>~<利率>~<年限月>~<寬限月>~<現金>~<月可支配>~<年化>~<波動>~<房價>~<房價漲幅>~<稅率>~<模式>~<提前還款方式>~<seed>~<路徑數>~<列舉扣除>~<計轉貸>
```

- 版本前綴 `s1`。欄位固定順序，`~` 分隔，純十進位數字。
- 欄位不足時，缺的一律用預設值補（向後相容）；欄位多出來時忽略（向前相容）。
- `模式`：`0` 固定報酬 / `1` 蒙地卡羅。`提前還款方式`：`0` 縮短年限 / `1` 縮短月付。布林：`0` / `1`。
- 刻意採人類可讀格式而非壓縮：這是一個以透明度為賣點的工具，連它的分享連結都應該看得懂。
- 更新時機：任一參數變動後 300ms debounce，用 `history.replaceState()` 寫入（不污染上一頁記錄）。`hashchange` 事件（使用者手動改網址或按上一頁）觸發重新載入參數。

### 7.2 localStorage 鍵

| 鍵 | 內容 |
|---|---|
| `mortgage-sandbox-tw:v1:last` | 最後一次的參數 hash 字串。下次進站若無 URL hash 則詢問「要接續上次的情境嗎」（toast 帶按鈕，不自動套用） |
| `mortgage-sandbox-tw:v1:scenarios` | 情境陣列，最多 12 筆，每筆 `{id, name, hash, savedAt}` |
| `mortgage-sandbox-tw:v1:seen` | 是否首訪。首訪時 scrubber 首次 focus 會顯示一次鍵盤提示列 |

所有寫入都包在 try/catch，失敗走 §4.5。

## 8. 無障礙

- 圖表 `<svg>` 加 `role="img"` 與 `<title>` `<desc>`，`<desc>` 內容由 JS 即時更新為當前結論的文字版本（三條路徑第 30 年的值 + 交叉點）。
- 圖表旁有一個視覺隱藏但可被螢幕閱讀器讀取的 `<table>`（`.sr-only`），列出每 5 年的三條路徑數值。圖不是唯一的資訊來源。
- scrubber 拖曳時 `aria-valuetext` 更新節流到 200ms，避免螢幕閱讀器被灌爆。
- 交叉點誕生時，`aria-live="polite"` 區域播報「第 11 年 3 個月，投資開始領先」。動效有的資訊，非視覺使用者也要有。
- 三條路徑不靠顏色分辨：同色相三個明度階 **加上** 三種線型（實線 / 長虛線 / 點線），legend 顯示真實線型。色盲與黑白列印皆可分辨。
- 所有互動元素的可點區域 >= 44 x 44 px（視覺尺寸可以更小，用 `::before` 撐開命中區）。
- `lang="zh-Hant-TW"`，數字區塊不設 `lang`（避免螢幕閱讀器把 mono 數字唸成英文序列）。
