# 房貸沙盤 / Mortgage Sandbox TW

## 一句話機制

把「提前還款」「只繳月付並投資差額」「用寬限期並投資差額」三條路徑，放在**同一條淨資產時間軸上對撞**，並讓使用者用滑桿親手把結論翻轉一次。

競品做的是「填表 → 出表格」。這裡做的是「拖時間軸 → 看三條線交叉 → 改假設 → 看交叉點移動」。差別在於前者給你一個答案，後者給你一個**答案對哪些假設敏感**的地圖。

---

## 受眾的真實使用場景

**誰**：30 到 45 歲、名下有一筆自住房貸、餘額約 800 萬到 1,500 萬、每年會有一筆 30 萬到 80 萬的可動用現金（年終、分紅、股息、解約的定存）。有基本理財概念，會看 ETF，但不會自己開 Excel 拉攤還表。

**在哪**：白天或傍晚，桌機或筆電，公司午休、下班後書房。不是通勤時滑手機的情境。這個決策要花 20 分鐘，需要坐下來。

**什麼時候**：三個高峰。
1. 每年 1 到 2 月，年終獎金入帳後。
2. 升息或降息公告後的兩週內。
3. 寬限期即將到期前的三個月。

**什麼情緒**：焦慮混著不服氣。
焦慮的來源是金額大到不能亂猜，但市面上沒有任何一個工具願意把假設攤開。不服氣的來源是每個人都給他一句斬釘截鐵的建議（「利率比報酬低就別急著還」「有貸款壓力就是不安穩」），而那句話背後的假設從來沒被說出來。

他要的不是「你應該怎麼做」，是「在什麼條件下這個做法會贏，那個條件成不成立我自己判斷」。

**帶著什麼進來**：他手上通常已經有三個數字（貸款餘額、利率、剩餘年限），這三個數字在銀行 App 的第一頁。所以輸入摩擦必須壓在三個欄位以內就能出圖。其他全部給合理預設並標示為預設。

## 這個介面必須證明什麼

### 1. 「我算過了，而且你可以查我的算法」

信任是這個產品的全部。每一個出現在畫面上的數字，都必須能回答「這個數字怎麼來的」。實作上這代表：

- 每個假設旁邊都有一個可展開的抽屜，裡面有**公式本身**（不是公式的文字描述）、代入的數值、以及來源或「這是假設不是資料」的標示。
- 所有假設常數集中在 `js/assumptions.js`，UI 直接讀它渲染抽屜。法規變動只改一個檔。
- 攤還表可以整張展開逐月看。使用者能拿去跟銀行的還款試算對帳。對得上，信任就建立了。

### 2. 「結論是你的假設推出來的，不是我的立場」

同一組貸款條件，報酬率從 3% 拉到 7%，結論會從「還款贏」翻成「投資贏」。這個翻轉必須**看得見、摸得到、可以來回撥**。這是產品的論點：這題沒有普世答案，只有你的假設。

具體要求：拖動報酬率滑桿時，交叉點必須沿著曲線滑動，而不是整張圖重畫。使用者要能感覺到那是**同一個世界的連續變形**。

### 3. 「我知道你在台灣」

- 寬限期（本國房貸特有的產品結構，國外試算器完全沒有）
- 提前清償違約金與綁約期
- 轉貸成本（代書費、抵押權設定登記費、塗銷費）
- 房貸利息列舉扣除額（所得稅法第 17 條，每戶每年上限 30 萬，且需先減除儲蓄投資特別扣除額）
- 新青安與一般房貸的利率預設，一鍵套用

這五項是中文市場的護城河。任何一個算錯，整個產品的可信度歸零。

### 4. 「這張圖可以被貼到 PTT 上」

分享連結必須完整還原情境，包含蒙地卡羅的那張圖。這代表 PRNG 必須是 seeded 的自製實作（mulberry32），`Math.random()` 一次都不能出現在模擬路徑裡。連結貼出去後別人打開看到的圖，必須跟你螢幕上的圖一模一樣，否則討論就無法進行。

## 絕對不能出錯的地方

依「錯了會死」的程度排序。

### 死級：數學

| 項目 | 正確做法 | 常見錯法 |
|---|---|---|
| 本息均攤月付 | `PMT = P * i / (1 - (1+i)^-n)`，`i = 年利率 / 12` | 用單利、或把 `i` 寫成年利率 |
| `i = 0` 的邊界 | 退化為 `PMT = P / n` | 除以零產生 `NaN`，整張圖消失 |
| 逐月攤還 | 先算利息 `bal * i`，再算本金 `PMT - 利息`，最後扣餘額 | 順序顛倒，本金多算一期利息 |
| 最後一期 | 餘額不足時，最後一期 `PMT` 改為 `bal * (1 + i)`，餘額歸零 | 留下 0.03 元的殘值，或負餘額 |
| 提前還款（縮短年限） | 月付不變，重算期數 `n' = ceil( -ln(1 - bal*i/PMT) / ln(1+i) )` | 直接把年限減掉「還款金額 / 月付」 |
| 提前還款（縮短月付） | 期數不變，用新餘額與剩餘期數重算 `PMT'` | 按比例縮放舊月付 |
| 寬限期 | 期間月付 = `bal * i`（本金不動）；期滿以剩餘本金與**剩餘期數**重算 `PMT'` | 期滿後沿用原月付，等於憑空少還一段本金 |
| 投資月報酬 | 幾何：`r_m = (1 + 年化)^(1/12) - 1` | 算術：`年化 / 12`，30 年下來高估數個百分點 |
| 蒙地卡羅漂移項 | 對數常態，`mu_m = ln(1+年化)/12 - sigma_m^2 / 2`，`sigma_m = 年化波動 / sqrt(12)` | 漏掉 `- sigma^2/2`，中位數被系統性高估 |
| 常態亂數 | Box-Muller：`z = sqrt(-2 ln u1) * cos(2*pi*u2)`，且 `u1` 需排除 0 | `u1 = 0` 時 `ln(0) = -Infinity` |
| PRNG | 自製 mulberry32，seed 進 URL | `Math.random()`，分享連結還原不出同一張圖 |

### 死級：淨資產的定義

規格草稿裡有一個會重複扣款的寫法：「房屋淨值（房價 - 貸款餘額）+ 投資部位 - 剩餘貸款」。這會把貸款餘額扣兩次。

**本專案採用的唯一定義，且必須顯示在圖表旁邊：**

```
淨資產(t) = 房屋價值(t) - 貸款餘額(t) + 投資部位(t) + 現金餘額(t)

其中：
  房屋價值(t) = 房屋現值 * (1 + 房價年漲幅)^(t/12)
  房屋淨值(t) = 房屋價值(t) - 貸款餘額(t)   ← 這是給人看的分解，不是額外的加項
```

這個定義要能被點開，抽屜裡逐項列出當期的四個分量與加總。使用者只要能自己驗一次，這個產品就贏了。

### 死級：三條路徑的比較基準

三條路徑如果起始資源不同，比較就是假的。基準必須是：

- 三條路徑的**期初可動用現金**都是 `L`
- 三條路徑的**每月現金流上限**都是 `C`
- 差別只在 `L` 和 `C - 當期房貸支出` 流向哪裡

| 路徑 | 期初 `L` | 每月 `C` 的分配 |
|---|---|---|
| A 全額提前還款 | 全數提前還款 | 先付當期月付，餘額全部繼續提前還款；貸款清償後才轉入投資 |
| B 只繳月付，差額投資 | 全數投入投資 | 付當期月付，`C - 月付` 全數投資 |
| C 寬限期 + 投資 | 全數投入投資 | 寬限期內付利息，`C - 利息` 投資；期滿後付新月付，`C - 新月付` 投資 |

這張表要出現在 UI 上，不是只在文件裡。使用者不接受這個基準的話，整張圖對他就沒有意義，他有權知道。

### 重級：假設與資料的界線

**規則：任何我們無法標示出處的數字，一律呈現為「可調假設」，不得呈現為「資料」。**

- 投資年化報酬預設 6.0%：這是假設。抽屜寫明它是**名目**報酬，並說明「房貸利率也是名目，兩邊同基準才可比；若要改用實質報酬，房價漲幅也要一起改成實質」。這句話是競品全部漏掉的一點。
- 年化波動預設 15.0%：這是假設。抽屜提供可查證的參考來源名稱，不引用我們無法驗證的具體數字。
- 房價年漲幅預設 2.0%：這是保守假設，不是預測。抽屜寫明「台灣各縣市差異極大，請用你標的區域的實際情況替換」並指向內政部不動產資訊平台的住宅價格指數。
- 利率預設：一般房貸與新青安兩組一鍵套用，標示為「參考值，請以你的貸款合約為準」。

抽屜裡不出現任何我們編造的小數點。編造的精確度比誠實的粗略更傷信任。

### 重級：不能把工具做成推銷

導流區塊（轉貸比較、券商開戶）只出現在結論之後，明確標示為推薦連結，且**不隨結論改變位置或大小**。如果偏還款的結論會讓轉貸連結變大，這個工具就不再中立，使用者感覺得出來。

## 競品在哪裡讓使用者失望

| 競品類型 | 具體失望點 |
|---|---|
| 591、各銀行官網試算 | 只能算月付與總利息。完全沒有「這筆錢拿去投資會怎樣」的對照。使用者算完還是不知道要幹嘛。 |
| 買房 vs 租房試算器（搜尋前十有八個） | 解的是另一題。使用者在意的是「已經買了，接下來這筆現金怎麼配」。 |
| 財經部落格的 Excel 檔 | 假設寫死在儲存格裡，改一個數字要看懂整張表。而且下載下來多半版本不對、公式壞掉。 |
| 國外的 mortgage payoff calculator | 沒有寬限期，沒有提前清償違約金，沒有台灣的利息扣除額。算出來的結論對台灣人是錯的。 |
| 所有競品的共通病 | **假設不揭露**。年化報酬多少？通膨算不算？房價漲幅哪來的？稅呢？畫面上看不到，也點不開。使用者只能選擇相信或不信，沒有第三個選項。 |
| 使用者體驗 | Bootstrap 表單、滿版廣告、行動裝置破版、送出後跳到另一頁看結果、改一個參數要重填整張表。 |

**這個產品的每一個設計決策，都要能對應回上表的某一格。**

## 成功長什麼樣

一個使用者在 20 分鐘後關掉分頁，他能對配偶說出這句話：

> 「按我們的條件，投資要年化超過 4.6% 才會贏過提前還款，而且要到第 11 年才看得出來。我覺得那個報酬率我做不到穩，所以我先還一半。」

他說得出**門檻**、說得出**時間**、說得出**他自己的判斷**。三樣都是這個介面給的，而最後一樣是這個介面刻意不給答案換來的。
