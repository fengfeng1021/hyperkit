# 六個視覺世界（已鎖定，不可自行更改）

這是 pinned brief。impeccable 的規則裡，brief-pinned direction 勝過 concept-seed 的隨機指派，
所以各專案**不需**執行 concept-seed，直接採用下方指派的世界並在其中深化。

鎖定的原因：六個站若各自決定，會全部收斂到同一種 AI 預設美學（暖米白＋襯線＋赭紅，或近黑＋霓虹）。
下方六個世界的色彩家族、明暗、字型、材質**兩兩互不重疊**，這是整個作品集能成立的前提。

---

## 1. invoice-wrapped-tw / 發票回顧

- **明暗**：暗。使用場景是晚上滑手機看自己的年度回顧、截圖分享，沉浸式。
- **世界**：收銀機列印的那捲紙 + 電子發票載具條碼掃描。不是「紙的懷舊」，是「機器吐出資料」的那一刻。
- **色彩**：深靛近黑底（`#0B0D17` 家族）／熱感應紙的高對比白／**朱橘紅**為唯一 accent（統一發票紅的現代化，`#FF4D2E` 家族）／條碼黑。
  - 明確禁止：米白背景、黃銅、任何「紙質懷舊」的暖色調。
- **字型**：顯示 `Archivo`（含 Expanded / Black 字重，數字要有壓迫感）／中文 `Noto Sans TC`／等寬 `Martian Mono`（發票號碼、金額）。
- **材質語言**：等寬對齊的資料列、齒孔邊緣、掃描光帶、條碼的粗細節奏。圓角極小（2px）或全直角。
- **介面語言**：繁體中文。

## 2. mortgage-sandbox-tw / 房貸沙盤

- **明暗**：亮。使用場景是白天認真研究一筆幾百萬的決策，需要清醒、可信、能長時間閱讀數字。
- **世界**：工程製圖／建築藍圖／方格紙上的手繪曲線。可信度來自「這是被計算過的」，不是「這很漂亮」。
- **色彩**：冷白底（`#F7F9FC` 家族，**冷**不是暖，禁止任何米色）／**深普魯士藍**線與文字（`#12305C` 家族）／淺灰藍方格（`#DCE4EF`）／**暖橘**唯一訊號色，只用在交叉點與結論（`#E86A2B`）。
- **字型**：顯示 `Schibsted Grotesk`／中文 `Noto Sans TC`／等寬 `JetBrains Mono`（所有金額、利率、年期一律等寬對齊）。
- **材質語言**：1px 方格底紋、hairline 座標軸、製圖用的引線與標註 pill、圓角 0-4px。
- **介面語言**：繁體中文。

## 3. cutout-forge / 去背熔爐

- **明暗**：暗。使用場景是盯著 200 張縮圖牆等待處理完成；暗底讓商品圖與透明棋盤格跳出來，也是專業影像工具的慣例。
- **世界**：工業製程監控台。掃描、量測、批次佇列、進度。不是賽博龐克霓虹。
- **色彩**：深炭黑底（`#0E0E10` 家族）／**電光青**為主 accent（掃描光帶、進度、`#22E5C8` 家族）／熔爐橙僅用於錯誤與警告（`#FF7A18`）／中性灰階做 UI 層級。
  - 與 #1 的區別：#1 是暖橘紅為主，#3 是冷青為主。兩者不得互換。
- **字型**：顯示與 UI `Geist`／等寬 `Geist Mono`（檔名、尺寸、佇列編號）。
- **材質語言**：棋盤格透明底、掃描光帶、精密的 1px 網格、佇列狀態燈、圓角 4px。
- **介面語言**：英文為主（全球電商賣家市場）。

## 4. mockup-loom / 情境織機

- **明暗**：亮，但是**中性偏暗的工作灰**。使用場景是判斷商品圖的顏色是否正確——背景必須中性，不能有色偏。
- **世界**：紡織／印染工坊。提花織機的打孔卡、布料樣本冊、染缸。
- **色彩**：中性工作灰底（`#E6E4E1` 到 `#2A2A28` 的中性階，**無色偏**）／**深橄欖**（`#4A5233`）／**磚紅** accent（`#B5462F`）。
  - 明確禁止：黃銅、赭石、任何會讓人聯想到「手工藝品牌」的暖米白。這裡的灰必須是中性的攝影棚灰。
- **字型**：顯示 `Bricolage Grotesque`（可變字體，有手感與寬度變化，呼應織品）／等寬 `Fragment Mono`。
- **材質語言**：織紋、樣本冊的邊角、打孔卡的孔洞節奏、布料的位移感。圓角 0（樣本卡是直角裁切的）。
- **介面語言**：英文為主。

## 5. gradientkit / 漸層工坊

- **明暗**：暗，近乎純黑。這是量測環境。
- **世界**：光譜量測儀／色彩實驗室。介面本身**幾乎沒有顏色**——所有顏色都來自使用者正在做的那個漸層。這是唯一正確的決策：一個顏色工具的介面若有自己的品牌色，就會污染使用者的色彩判斷。
- **色彩策略**：`Drenched by the user's own work`。純黑底（`#000`／`#0A0A0A`）／白色 hairline 與文字／一階中性灰。**介面零 accent 色**——highlight 用亮度與 1px 白線，不用色相。使用者的漸層是畫面上唯一的顏色。
- **字型**：顯示 `Sora`／等寬 `Fragment Mono`（OKLCH 數值、色碼）。
- **材質語言**：光學儀器的細線刻度、色標、數值讀數、無圓角或 2px。顏色以外的一切都是黑白。
- **介面語言**：英文為主。

## 6. chatvault / 對話金庫

- **明暗**：亮。使用場景是長時間閱讀大量文字。
- **世界**：圖書館卡片目錄櫃／檔案索引。分類、標籤、抽屜、卡片、交叉索引。
- **色彩**：冷紙灰底（`#F2F2EF`，冷灰不是米黃）／深墨黑文字（`#1C1C1A`）／**琥珀/芥末黃** accent（`#C8901A` 家族，索引標籤的顏色）／一階冷灰做分隔。
  - 與 #4 的區別：#4 是中性攝影灰＋橄欖磚紅，#6 是冷紙灰＋琥珀。
- **字型**：**唯一允許使用襯線的專案** —— 這是長文閱讀產品，襯線在此有功能理由（可讀性）與世界理由（目錄卡片的排印傳統）。用 `Literata`（內文與顯示）／UI 標籤 `Public Sans`。
  - 依然禁止 Fraunces / Instrument Serif / Playfair / Cormorant。
- **材質語言**：索引卡的邊、標籤凸出、抽屜滑軌、細分隔線、圓角 2px。
- **介面語言**：英文為主。
