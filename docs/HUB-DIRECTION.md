# Hub 首頁方向契約

Hub 是第七個介面，不是六個之一的延伸。它的工作是：讓第一次來的人在幾秒內知道這是什麼、
六個工具各是什麼、並且**在還沒點進去之前就已經感受到六個工具是六個不同的世界**。

## 方向契約

**THESIS**
這不是作品集列表頁。它是一個索引櫃：六個工具各自帶著自己完整的視覺世界，
你的游標停在哪一行，整個頁面就變成那個世界的顏色、那個世界的字。
它拒絕的類別預設是：六張等大卡片組成的網格（圖示 + 標題 + 兩行敘述），
以及它的可預期反面——一個滿版影片背景加一句大標語的 agency 首頁。

**OWN-WORLD**
櫃體是中性的近黑（`#0A0A0B`），整個結構由 1px hairline 構成——索引線、分隔線、框線。
頁面**本身沒有品牌色**：畫面上出現的每一個顏色都是某個工具借給它的。
這是唯一誠實的做法，因為 hub 的內容就是那六個世界。
排印是核心機制：六行工具名各自用該工具自己的顯示字型渲染
（Archivo / Schibsted Grotesk / Geist / Bricolage Grotesque / Sora / Literata），
所以你在索引上就已經讀到六種不同的排印個性。
字型用 Google Fonts 的 `&text=` 參數只載該行需要的字元，六個字型加起來不到 20KB。

**STORY**
訪客理解：這裡有六個能立刻用的瀏覽器工具，全部在本機運算，資料不上傳。
訪客相信：這些不是 demo——每一個都有真實功能，而且做得很細。
訪客做：把游標掃過索引（或在手機上往下捲），停在跟自己有關的那一個，點進去。

**FIRST VIEWPORT**
全螢幕，不需要捲動就看得完整個索引。
左上角 `HYPERKIT` 字樣與一行說明（六個瀏覽器工具，全部在你的裝置上運算）。
畫面主體左側 58% 是六行工具名的垂直索引，每行是大字（`clamp(2.2rem, 5.2vw, 4.6rem)`），
行與行之間只有 1px hairline，沒有卡片、沒有圖示、沒有 eyebrow。
右側 42% 是預覽視窗——顯示當前選中工具的**真實截圖**（不是假的 UI mockup）。
底部一條 hairline 狀態列：當前工具的一行定位、它解決的問題、以及進入的提示。
主要動作（進入工具）就是索引行本身，整行可點。

**FORM**
垂直索引 + 單一預覽視窗（form 排序中的第 2 位；第 1 位是「六個全螢幕橫向章節」，
被否決是因為它逼使用者依序看完六個才知道有什麼，違反 hub 的工作）。
seed key: brief-pinned（VISUAL-WORLDS.md 已將六個世界釘死，hub 採一致的 pinned 策略，不擲骰）。

**FINISH**
unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, and DESIGN.md

## 招牌動效時刻

**游標移到某一行的那 0.5 秒，整個頁面換一個世界。**

一條 GSAP timeline 同時：

1. `--bg` / `--fg` / `--accent` / `--hairline` 四個 CSS 變數 tween 到該工具的世界色
   （0.5s `power3.out`；GSAP 可直接 tween CSS 自訂屬性）
2. 該行從 hairline 灰提升到滿對比並換上該工具的顯示字型；
   其餘五行 `autoAlpha` 降到 0.32、`filter: blur(1.5px)`、`x: -6`，stagger `{ each: 0.02, from: 'start' }`
3. 右側預覽視窗：新截圖以 `clip-path: inset()` 從舊截圖上由左往右擦出（0.55s `expo.out`），
   擦除邊緣是一條 2px 該工具 accent 色的線，線走過之後才留下新畫面
4. 底部狀態列的文字用 SplitText 逐字替換（`stagger 0.012`）
5. 索引行左側的行號位置長出一條該工具 accent 色的短線（`scaleX 0 → 1`，`transformOrigin: left`）

離開索引區時，全部反向回到中性黑白。

**為什麼這個動效存在**：它同時完成三件事——回饋（你選中了哪一行）、
階層（被選中的行升起、其餘退開）、以及這個 hub 唯一想證明的事（六個工具是六個不同的世界）。
沒有它，這個頁面就只是一份清單。

## 行動裝置（沒有 hover）

改為垂直堆疊：每個工具是一個滿版區塊，帶自己的世界色與字型與截圖。
用 ScrollTrigger 在區塊進入視窗中央時把頁面色彩變數 tween 過去——
在手機上，捲動就是那個「換世界」的動作。
不是把桌機版縮小，是同一個概念的另一種手勢。

## 必須避開

1. 六張等大卡片的網格（craft-floor 明令：卡片是懶惰容器）
2. 任何 section 標題上方的 eyebrow 小標
3. hero 的大數字統計列（「6 個工具・100% 本機運算・0 上傳」這種三欄數字）
4. 漸層文字、玻璃模糊裝飾、彩色 border-left
5. emoji 當工具圖示

## 內容真實性

- 預覽圖必須是六個子站的**真實截圖**，用瀏覽器實際拍下來，不是手繪 mockup
- 不寫任何無法驗證的商業宣稱（使用者數、下載量、評價）
- 「資料不離開瀏覽器」是可驗證的技術事實，可以寫，並且要能指向各站的說明
