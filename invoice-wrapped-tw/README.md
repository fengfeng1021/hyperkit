# 發票回顧 / Invoice Wrapped TW

把財政部電子發票載具匯出的消費明細 CSV，在瀏覽器裡就地解析成一份可探索的年度消費結構，
再收攏成一段十屏的年度敘事，最後撕下一張 1080 × 1920 的直式圖卡。

**全程沒有任何一個位元離開這台裝置。**

---

## 這是什麼

它不是記帳 App，記帳 App 要你每天記。
它不是對獎工具，對獎工具只關心那張中了沒。

它是一台離線的資料印表機：你把一整年的原始交易記錄餵進去，它印出你今年真正的樣子。
造訪次數的長尾、星期 × 時段的行為指紋、最貴的那一筆、最晚的那一次、花得最兇的那一週。

語氣是儀器不是教練。它報數字、給脈絡，不下判斷。

---

## 怎麼用

### 1. 拿到你的 CSV

1. 登入 [財政部電子發票整合服務平台](https://www.einvoice.nat.gov.tw)（手機條碼、自然人憑證或已註冊帳號）
2. 左側選單進入「載具管理」，點「消費明細」
3. 選好年度與月份區間，檔案格式選 CSV 再下載

一次只能抓半年的話就抓兩次，這個站會自動合併並依發票號碼去重。

### 2. 丟進來

把檔案拖到首屏右邊的進紙口，或按「選擇 CSV 檔案」。
沒有自己的檔案也可以：按「載入範例資料」，用 `assets/sample-invoice.csv`
（2025 年、780 筆虛構消費、86 家店、涵蓋 12 個月，其中 46 家只去過一次）立刻看到完整成果。
範例模式下頁面頂端會常駐一條標記帶，分享圖卡右下角也會印「範例資料」，不會讓任何人誤會。

### 3. 攤開來看

- **星期 × 時段熱力圖**：點一格，下面的明細表只留那個時段
- **月度金額折線**：方向鍵切換月份
- **店家泡泡雲**：面積是金額，濃淡與條紋是分類，點一顆展開該店家的逐筆消費
- **分類到店家的流向圖**：拖曳右欄節點重排，鍵盤用 Alt + 上下鍵
- **逐筆明細表**：虛擬捲動、搜尋、篩選標籤，Enter 展開品項
- **回饋試算**：費率可編輯，附「這個數字怎麼算的」逐項展開

### 4. 收攏成敘事

按「產生年度回顧」（或按 `G` 再按 `W`）進入十屏全螢幕敘事，最後一屏產出直式圖卡。
四種版型：收據 / 單一數字 / 年輪 / 熱力。可以一鍵把所有金額遮成實心方塊。

### 快捷鍵

| 鍵 | 行為 |
|---|---|
| `/` | 跳到明細表搜尋 |
| `G` `W` | 打開年度回顧 |
| `Esc` | 由內而外收合一層 |
| 方向鍵 | 在熱力圖、折線、泡泡雲、明細表裡移動 |
| `Alt` + 上下鍵 | 在流向圖裡重排店家順序 |
| `?` | 開關快捷鍵清單 |

## 隱私聲明

**你的消費明細沒有被上傳，因為這個頁面沒有任何上傳的程式碼路徑。**

- 解析、統計、繪圖、產圖卡全部在這個分頁的記憶體與 canvas 裡完成
- 沒有後端、沒有 analytics、沒有錯誤回報、沒有字型子集 API、沒有截圖服務
- 分享圖卡由站內離屏 canvas 自繪並用 `canvas.toBlob()` 存成 PNG
- 只有兩類東西寫進你自己的瀏覽器：
  - `localStorage`（`iwtw:` 前綴）：欄位對映、手動分類、回饋費率
  - `IndexedDB`（`iwtw` / `years`）：歷年**彙總**（不留逐筆原始列），用來解鎖年度比較
- 這兩者都可以在頁面上逐筆刪除

這不是一句標語，是可以當場驗證的：

1. 站頭右側的離線指示燈點開，會即時列出這個頁面發出過的**每一筆**網路請求
   （用 `PerformanceObserver` 讀 resource timing），並標示「上傳請求：0」
2. 頁面下方「這個頁面發出過哪些網路請求」有同一份清單的完整版
3. 最直接的做法：**拔掉網路連線，重新整理，再跑一次**。
   除了 Google Fonts 與 GSAP CDN 會換成備援字型與純 CSS 行為，其餘功能完全一樣

唯一的三個外部來源是 Google Fonts（Archivo / Noto Sans TC / Martian Mono）與 jsDelivr 上的 GSAP，
它們只下載資源，不接收任何東西。

## 技術要點

### 零 build

原生 HTML + CSS 自訂屬性 + ES modules。沒有 npm、沒有 bundler、沒有框架。
所有資源路徑都是相對路徑，可以直接放在任何子目錄下服務。

### CSV 解析器的三層防禦

財政部的匯出格式會改版，編碼可能是 Big5 也可能是 UTF-8 BOM，所以解析器沒有任何寫死的欄位索引。

1. **編碼偵測**：先用 `TextDecoder('utf-8', { fatal: true })` 嚴格解，過了就一定是 UTF-8。
   失敗才同時試寬鬆 UTF-8 與 `TextDecoder('big5')`，比較 U+FFFD 比例與 CJK 密度後選一個。
   兩者都不乾淨時開啟編碼選擇器，附前五列的即時解碼預覽讓使用者自己選。
2. **欄位自動對映**：欄位是靠「這一欄長得像什麼」推出來的。
   發票號碼比對 `[A-Z]{2}\d{8}`、日期支援西元/民國/含時間/不含時間四種寫法、
   統編比對八位數字、金額取最後一個純數字欄、店名取剩下欄位裡平均字數最長的那個。
3. **欄位對映精靈**：推不出來（或使用者覺得推錯了）就原地展開一個非 modal 的面板：
   前 8 列等寬預覽、每欄一個原生 `<select>`、旁邊印出型別偵測結果、
   下方即時預覽「依這個對映會解析出這樣的 3 筆資料」。
   對映結果以欄位型別指紋的雜湊當 key 存進 `localStorage`，同結構的檔案下次自動套用。

CSV tokenizer 是 RFC 4180 狀態機，處理引號內的逗號與換行、雙引號跳脫、CRLF/LF/CR 三種行尾。

### 金額不會算錯

- **一律以「分」為單位的整數計算**，只在輸出時除以 100。七百筆累加不會跑出 `NT$248,309.99999`
- 去重規則明確：同一發票號碼只計一次主檔金額，後匯入的覆蓋先前的
- **`D` 明細列的小計不與 `M` 主檔的總金額相加**。展開明細時如果兩者不同，介面會直接說明以主檔為準
- 金額超界（負數或絕對值超過 10 億）的列不丟棄，標記為異常、列進明細但不計入統計

### 不靜默失敗

每一次解析都回報「讀進 N 列、成功 M 列、跳過 K 列」，而且可以展開看被跳過的原始文字與跳過原因。
解析在主執行緒分塊進行（每三塊讓出一次），進度是真實百分比不是不確定進度條，Esc 或取消鈕可以中斷。

### 視覺化

- 熱力圖是 DOM `role="grid"`，一個 tab stop + 方向鍵，不是 168 個 tab stop
- 泡泡雲是 canvas + 自寫的碰撞鬆弛力學（不引入 d3），DPR-aware，收斂後停止 rAF。
  旁邊附一個視覺隱藏的前 20 名 `<table>` 給螢幕閱讀器
- 分享圖卡的條碼是**真的 Code 128**（Set B，含 mod 103 檢查碼），不是隨機粗細的線條
- 分類不靠色相區分。整個世界只有一種油墨，分類靠單一朱橘紅階的濃淡、
  條紋密度（0 到 5 條 / 12px）與自繪圖示三重編碼，色覺辨識障礙使用者也分得出來

### 降級路徑

| 情況 | 行為 |
|---|---|
| GSAP CDN 載不到 | 所有內容維持預設可見，互動改用 CSS transition。頁面完全可用 |
| Google Fonts 載不到 | fallback 到 Arial Narrow / PingFang TC / Consolas 堆疊 |
| 瀏覽器不支援 Big5 解碼 | 只在需要時提示，UTF-8 路徑不受影響 |
| Canvas 被停用 | 泡泡雲換成排行表，折線換成數字表，其餘功能正常 |
| `localStorage` 寫不進去（無痕 / 配額滿） | 全站改用記憶體內 fallback 並明講「這次照常運作，但設定不會被記住」 |
| IndexedDB 配額吃緊 | 事前用 `navigator.storage.estimate()` 檢查，不足時只存彙總丟棄逐筆 |
| `prefers-reduced-motion` | 掃描光帶靜止在中線、印字頭停止跳動、捲動改為瞬時。內容一個字都不少 |

## 在本機跑

因為用的是原生 ES modules 與 `fetch`，需要一個靜態伺服器（`file://` 下瀏覽器會擋掉 module 與本地檔案讀取）。

```bash
cd invoice-wrapped-tw
python -m http.server 4141
# 或
npx serve -l 4141 .
```

然後開 `http://localhost:4141/`。沒有安裝步驟，沒有編譯，改完檔案重新整理就好。

## 範例資料是怎麼來的

`assets/sample-invoice.csv` 是用固定 seed 的 PRNG 產生的虛構資料，不是任何真實個人的消費記錄。
它刻意做得符合台灣現實：86 家店分佈在超商 / 超市 / 餐飲 / 交通 / 藥妝 / 電商 / 其他七類，
其中 46 家一年只去過一次（真實的載具明細一定有這一段長尾），
時段權重依分類不同（超商有深夜、交通有通勤尖峰、餐飲有午晚餐雙峰），
月份權重反映農曆年與年底尾牙，金額走對數常態分佈。
檔案開頭保留了財政部匯出會有的三列格式說明，用來實測「跳過非資料列」這條路徑。

它同時是一份格式範本：想確認你的檔案能不能被讀，跟這一份對照欄位即可。
