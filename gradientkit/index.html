        範例櫃

        十二組漸層標本加三組網格，每一組都是為了示範一件特定的事而做的。載入之後就是你的，隨便改。

        每種輸出到底給你什麼

        CSS

        兩段。第一段是純 sRGB 漸層，色標是從 OKLCH 曲線上重新取九個位置抓下來的，所以不支援新式插值的瀏覽器拿到的還是接近的結果，而不是兩個色標硬猜出來的濁色。第二段包在 @supports 裡面，帶的是真正的 oklch() 值。兩段在給你複製之前，都先在你的瀏覽器裡用 CSS.supports() 驗過一次，面板會告訴你它驗到了哪一段。

        SVG

        真的 linearGradient 或 radialGradient，用 objectBoundingBox 單位，角度交給 gradientTransform 帶。SVG 漸層只有 sRGB，所以色標會重新取十七個位置。圓錐漸層在 SVG 裡根本沒有對應的原生元素，所以那個分頁改成嵌一張 512px 的點陣圖，內容就是載物台上看到的樣子，而且會明講——不會默默丟一段畫出來不一樣的東西給你。

        Tailwind

        一段 v4 的 @theme，裡面有漸層本身加三個衍生的顏色 token，utility 怎麼用寫在註解裡。不產 v3 的 config 物件：v3 config 正是 v4 要取代掉的東西，現在還吐一份出來，等於第一天就過時。

        PNG

        用同一支 shader 直接在目標尺寸算一次，所以抖色和顆粒是在全解析度上長出來的，不是從預覽放大的。如果裝置配不出 4096px 的畫布，會退回 2048px 重試，並且告訴你它退了。色覺模擬永遠不會被烤進檔案裡。

        什麼時候真的需要備援

        各家瀏覽器引擎對 OKLCH 漸層插值的支援度

        這裡的版本指的是漸層插值，也就是寫成 in oklch 的那個。oklch() 這個顏色函式本身在每家引擎都更早就有了。如果你的使用者環境比較封閉，上線前先去 caniuse.com 確認一下現況。

        隱私

        全部都在這個分頁裡跑。不用帳號、不上傳、沒有追蹤。你存的漸層只會進這個瀏覽器的本機儲存，不會去別的地方；丟進來的圖在記憶體裡解碼，從頭到尾沒離開過這一頁；分享連結是把整個漸層塞在網址裡，不是放在某台伺服器上。

        出處

        OKLab 與 sRGB 色域對應依照 Bjorn Ottosson 的推導和 CSS Color 4 規格。色覺矩陣出自 Machado、Oliveira 與 Fernandes，2009 年。圖示是 Lucide，ISC 授權。字型是 Sora、Fragment Mono 與 Noto Sans TC。
