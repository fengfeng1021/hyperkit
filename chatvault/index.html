一個搜尋框。

把 ChatGPT、Claude 或 Gemini 的匯出檔丟進來。解析、建索引、閱讀都在這個分頁裡完成，沒有東西上傳。

把匯出檔拖到這裡

或點一下選檔案

你的匯出檔是怎麼被讀進來的

  1. ChatGPT

    每筆紀錄帶著一個 mapping，裡面是一堆有 parent 和 children 的節點，外加一個 current_node 葉節點。對話金庫從那個葉節點沿著 parent 往回走，還原你當時真正看到的那條對話，其他分支也一起建索引並標記出來。

  2. Claude

    每筆紀錄帶著 chat_messages，每一則的 sender 是 human 或 assistant，內文可能放在 text，也可能放在 content 這個分型別的區塊陣列裡。兩種寫法都讀得懂。

  3. Gemini

    Google Takeout 的活動紀錄，可以是帶 Gemini header 和 time 的 JSON，也可以是 MyActivity 的 HTML 頁面。Takeout 不會把來回的訊息歸成一段對話，所以對話金庫用間隔 30 分鐘來分組，並在閱讀區直接寫明這件事。

  4. 其他格式

    三種結構都對不上時，由你自己指認欄位。這份對應會用檔案 key 結構的雜湊存起來，下次同格式的匯出檔就不會再問你一次。

怎麼拿到匯出檔

  1. 打開 Settings，進 Data controls，點 Export data。
  2. 按確認。連結會寄到信箱，通常幾分鐘內就到，資料量大的帳號有時要等幾小時。
  3. 下載連結 24 小時後失效，先把 zip 存到本機再說。
  4. 整包 zip 直接丟進來。對話金庫只從裡面讀 conversations.json，其餘不會解開。
  1. 打開 Settings，進 Privacy，點 Export data。
  2. 按確認。連結會寄到信箱，通常幾分鐘內就到。
  3. zip 裡除了 conversations.json，還有一些帳號檔案，那些會被略過。
  4. 把 zip 丟進來。如果你的瀏覽器沒辦法在頁面裡解壓縮，就自己解開，改丟 conversations.json。
  1. 到 Google Takeout，先把全部項目取消勾選。
  2. 只勾 My Activity，用格式按鈕改成 JSON，再把範圍縮到 Gemini Apps。
  3. 送出匯出。Takeout 比另外兩家慢，看帳號大小，可能幾分鐘也可能一整天。
  4. 整包壓縮檔丟進來，或單獨丟 MyActivity.json、MyActivity.html 也行。

這個頁面會向網路要什麼

總共四個網域，你用工具的同時就能在 Network 面板一個一個核對。你的對話不在這張清單上，因為這個頁面裡根本沒有一個能把它送出去的端點。頁面和字型進了快取之後，你可以斷網繼續搜。

資料存在這個瀏覽器設定檔的 IndexedDB 裡。刪掉就是真的刪掉，別的地方沒有副本——這是這個設計刻意做的取捨。
