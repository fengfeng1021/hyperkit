正在偵測這個瀏覽器的檔案存取能力

資料流向

  1. 1本機資料夾瀏覽器授權後直接讀檔
  2. 2你的瀏覽器雜湊、比對、挑檔、估算都在這一頁
  3. 3你自己的 API key存在 localStorage，只放進送往供應商的標頭
  4. 4供應商api.anthropic.com 或 api.openai.com

沒有第五個節點。這個站沒有後端、沒有分析、沒有錯誤回報服務。你可以打開 Network 分頁自己驗。

跟「叫 agent 審查一下」的差別

叫 agent 審查一下這台儀器
回你一段散文，要自己讀完一份有檔案、行號、嚴重度的清單
每次從零開始，誤報講一百遍你標記過的，之後自動不顯示
聊天記錄不能寄給客戶一份 Markdown 報告，含審查範圍聲明

這張表是誠實的：agent 也能審查，只是輸出形式不同。承認對手的能力比假裝對手不存在有說服力。

瀏覽器支援

  • Chrome / Edge / Opera完整。File System Access API 可用，資料夾授權存在本機，回訪時一鍵續用。
  • Firefox / Safari可用，但沒有持久授權。走 webkitdirectory 一次選整個資料夾，功能完整，只是每次回來都要重選一次。基準線與判讀規則仍然保留在本機。
  • 全部瀏覽器SHA-256 雜湊需要 secure context。用 https 或 localhost 開啟即可，本站兩者皆符合。
